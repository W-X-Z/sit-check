# 실험 진행 가이드 (v0.2)

[자세 감지 방향성 리서치](posture-detection-research.md)의 방법론을 앱에 적용했다. 핵심은 **'바른 자세'를 판정하지 않고, 먼저 재고 나서 알린다**는 것이다.

## 무엇이 바뀌었나

| 항목 | 이전 | 지금 |
|---|---|---|
| 카메라 알림 | R2 기울기·회전, R3 화면 접근 카드 | **기록만** (측정 기간 기본값). R2·R3은 '예전 규칙이었다면 울렸을 알림'으로만 기록 |
| 새 신호 | — | R5 오래 같은 자세, R6 앉은 직후보다 아래로·가까이, R7 가까움(거리 보정 시) |
| 임계값 | 고정 각도·비율 (12°, 18°, +15%) | 개인 흔들림(σ)의 배수. '가만히 5분' 측정 또는 자동 기준에서 얻음 |
| 기준 자세 | '바른 자세' 3초 저장 | '평소 자세' 10초 저장 + 앉은 직후 2–15분으로 만드는 자동 기준 (공통 기준 거름망 없음) |
| 좌우 값 | 카드에 사용 | 카드에 쓰지 않음. 움직임 감지와 비공개 기록에만 |
| 카메라 | 시스템 기본 카메라, 프레임 속도 제한 없음 | 내장 카메라 고정, 최저 프레임 속도, 각도 값이 없으면 0°가 아니라 '없음' |
| 기록 | 없음 | 1분 단위 요약(중앙값·흩어짐·CPU·분석 시간), '울렸을 알림', 확인 질문 답 |
| 카드 | 바로 띄움 | 타이핑이 멈출 때 띄우고(최대 5분), 통화 중엔 미룸(최대 30분). 카메라 카드는 하루 3장, 무시하면 간격 2배 |
| 카메라 카드 문구 | 스트레칭 2개 | 사실 + 선택할 수 있는 움직임 하나 + "맞았나요?" (맞아요 / 아니에요 / 자리가 바뀌었어요) |

40분 착석 카드(R1)와 호흡 신호(R4)는 그대로다.

## 터미널 명령

```bash
cd ~/Desktop/sit-check
git pull

# (선택, 한 번만) 재빌드해도 카메라 권한이 유지되게 자체 서명 인증서 만들기
./scripts/make-signing-identity.sh

# 앱 + 분석 도구 빌드
./scripts/make-app.sh

# 실행 중인 앱을 끄고 새로 실행
pkill -x SitCheck; open build/SitCheck.app

# 결과 보기
build/sitcheck-analyze report          # 전체 요약과 다음 할 일
build/sitcheck-analyze days            # 날짜별 기록량과 '울렸을 알림' (실험 5)
build/sitcheck-analyze cost            # 분석 구성별 CPU (실험 1)
build/sitcheck-analyze probes          # 3D 몸 자세·AirPods 확인 결과 (실험 1·2)
build/sitcheck-analyze noise           # 가만히 있을 때 흔들림 (실험 3)
build/sitcheck-analyze protocol        # 의도한 동작 구분 (실험 4)
build/sitcheck-analyze replay --still 20,30,45 --drift-k 2,3,4 --drift-hold 3,5,8 --split 7   # 판정값 고르기 (실험 5)
build/sitcheck-analyze feedback        # 카드 정확도, 확인 질문 (실험 7)
build/sitcheck-analyze outcomes        # 알림 뒤 10분 안에 일어났는지 (실험 8)
build/sitcheck-analyze export ~/Desktop/sitcheck-csv   # CSV로 내보내기

# 앱 CPU를 직접 보고 싶을 때 (10초 간격 6번)
top -l 6 -s 10 -pid "$(pgrep -x SitCheck)" -stats pid,cpu,mem | grep -E "^ *[0-9]+ "

# 기록 파일을 직접 볼 때
sqlite3 ~/Library/Application\ Support/SitCheck/sitcheck.sqlite \
  "select datetime(at,'unixepoch','localtime'), rule_id, variant, mode from posture_event order by at desc limit 20;"
```

빌드 오류가 나면 `make-app.sh`가 Command Line Tools 재설치 방법을 알려 준다. `swift test`는 Xcode가 있어야 돈다 (테스트는 CI에서 macOS 15 Apple silicon·Intel로 돈다).

## 일정과 통과 기준

숫자는 근거에서 나온 값이 아니라 출발값이다. 실험·측정 창은 메뉴바 아이콘 → **실험·측정…** 에서 연다.

| 시기 | 앱에서 할 일 | 터미널 | 통과 기준 | 결과에 따른 결정 |
|---|---|---|---|---|
| 0주차 (1분) | 실험·측정 창 → **평소 자세 저장 (10초)**. 편하게 앉아 화면을 보면 된다 | — | 얼굴이 5번 이상 잡힘 | 예전 R2·R3 비교 기록과 자동 기준 비교에 쓴다 (이 자세로 되돌리라고 알리지 않음) |
| 0주차 (반나절) | **실험 1** 분석 구성(얼굴만 / + 랜드마크 / + 2D 몸 자세)을 바꿔 가며 10분씩, 프레임 상한 켬·끔도 비교. '3D 몸 자세 동작 확인' 누르기 | `cost`, `probes` | 앱 전체 평균 CPU가 예산(예: 코어 1개의 3%) 안 | 상한 효과가 있으면 켜 둔다. 2D 몸 자세는 예산 안일 때만 실험 3·4에 쓴다. 3D는 실패하면 영구 제외, 성공해도 알림에 안 씀 |
| 0주차 (30분) | **실험 2** AirPods를 귀에 꽂고 'AirPods 동작 데이터 확인' | `probes` | 30초 동안 샘플이 끊김 없이 들어옴 | 안 들어오면 AirPods 경로를 접는다 (Intel Mac은 안 될 가능성이 큼) |
| 1주차 (5분 × 3) | **실험 3** 날짜·조명을 바꿔 '가만히 5분 측정' (안경을 쓴다면 쓴 채로도) | `noise` | 잡으려는 변화가 흔들림의 3배 이상 | 흔들림에 묻히는 특징은 알림에서 빼고 기록만 한다 |
| 1주차 (약 18분 × 2–3, 다른 날) | **실험 4** '의도한 동작 실험': 자연스럽게 앉기 → 무작위 순서로 7개 동작 → 의자 바꾸기, 2분씩 | `protocol` | 가라앉기·다가가기는 80% 이상 잡힘, 내려다보기·옆 화면·옆으로 기대기는 10% 이하 | 얼굴만으로 가라앉기와 내려다보기가 안 갈리면 분석 구성을 '+ 2D 몸 자세'로 바꿔 다시. 그래도 안 되면 R6은 카드 없이 요약으로만 |
| 아무 때나 (10분) | **실험 6** 줄자로 60 cm에 앉아 '60 cm에서 보정', 45·75 cm에서 '지금 추정 거리' 확인 | — | 오차 10% 이내 | 통과하면 R7(40 cm 미만이 10분) 기록 시작. 실패하면 보정을 지우고 cm는 쓰지 않음 |
| 1–2주차 | **실험 5** 평소대로 쓰기. 카메라 알림은 '기록만', R1 카드는 그대로. 하루 1–2번 확인 질문에 답하기. 자리를 바꾸면 메뉴의 '맞아요, 다시 배우기' | `days`, `replay --split 7` | 앉아 있을 때 얼굴이 잡힌 분 90% 이상. 1주차로 고른 값을 2주차에 적용해 유형별 '울렸을 알림'이 하루 중앙값 2회 이하·최대 3회 이하. 설치 변화 오인은 주 1회 이하 | 통과한 신호만 3주차에 켠다. 판정값은 설정에서 replay가 고른 값으로 바꾼다 |
| 3–6주차 | **실험 7** 카메라 알림을 '카드로 알림'으로. 카드의 "맞았나요?"에 가끔 답하기 | `feedback` | 유형별 정확도 0.8 이상, 잘못 뜬 자세 카드 하루 1장 이하 | 0.7–0.8이면 이어진 시간·기준을 올린다. 2주 연속 0.7 미만이면 그 카드는 없애고 아이콘·요약으로만 |
| 6–10주차 | **실험 8** '카드 대신 아이콘만'을 30–50%로 | `outcomes` | 카드 쪽이 아이콘 쪽보다 10분 안에 일어난 비율이 10%p 이상 높은 상태가 4주 유지 | 차이가 없으면 그 카드 유형을 없앤다. 있으면 유지하되 빈도를 서서히 줄인다 |

실험 3·4 중에는 카드와 확인 질문이 뜨지 않는다. 화면을 잠그면 실험이 멈춘다.

## 무엇을 저장하나

- 영상, 사진, 프레임별 좌표는 저장하지 않는다. 1초에 한 장 분석한 뒤 바로 버린다.
- 1분마다 남기는 것: 얼굴 위치·크기·각도의 중앙값과 흩어짐(MAD, 10·90 백분위), 얼굴이 잡힌 프레임 수, 분석 구성, 평균 분석 시간, 앱 CPU 사용률, 착석 구간 시작 시각, 실험 라벨.
- 이벤트: '울렸을 알림'(규칙, 변형, 값), 카드와 답, 확인 질문과 답, 착석 구간이 끝난 이유(자리 비움 / 잠금 / 다시 시작).
- 위치: `~/Library/Application Support/SitCheck/sitcheck.sqlite` (확인 결과는 같은 폴더의 `probes.log`). 네트워크는 쓰지 않는다.
- 설정 → 데이터 → **모든 기록 삭제**로 지운다 (설정은 남음).

## 알림이 판단하지 않는 것

- 좌우 대칭, 어깨 높이 차이, 고개 기울기의 '정답'. 진단 전에는 교정 방향을 제시하지 않는다 (NFR-09).
- 거북목 각도(CVA), 등 굽음. 화면 위 정면 카메라로는 잴 수 없다.
- 카드 문구는 무엇이 얼마나 이어졌는지만 말하고, 행동은 '원하면' 하는 일반적인 움직임 하나만 권한다.
